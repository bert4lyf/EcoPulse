## 🧪 Testing Offline Mode

### Method 1: Using the Offline Toggle Button

1. Open http://localhost:3000 in your browser
2. Look for the button in the **bottom-right corner**
3. Click to toggle between "Online Mode" (green) and "Offline Mode" (red)
4. The navbar status indicator will update accordingly
5. Shelter data will still display (loaded from cache)

### Method 2: Chrome DevTools (Service Worker Control)

1. Open your browser and visit http://localhost:3000
2. Open **Chrome DevTools** (Press `F12` or `Ctrl+Shift+I`)
3. Navigate to the **Application** tab
4. In the left sidebar, click **Service Workers**
5. Find the service worker entry
6. Check the **Offline** checkbox
7. Refresh the page with `Ctrl+R`
8. **The app will load completely from cache!**

### Method 3: Network Tab Offline

1. Open **Chrome DevTools** (`F12`)
2. Go to **Network** tab
3. Check the **Offline** checkbox
4. Refresh the page
5. App loads from cache with zero network requests

### Method 4: Disable Network Completely

1. Disconnect from WiFi or disable ethernet
2. Open http://localhost:3000 (if already loaded)
3. The app continues to work offline!

## 🚨 Troubleshooting

### Issue: "Service Worker not registered"
**Solution:**
1. Clear browser cache: `Ctrl+Shift+Delete`
2. Hard refresh: `Ctrl+Shift+R`
3. Check Console tab in DevTools for errors
4. Verify `next.config.ts` has PWA configuration

### Issue: "Offline mode not working"
**Solution:**
1. Ensure you've visited the site online first
2. Check DevTools → Application → Service Workers (should be "running")
3. Try DevTools offline method: Application → Service Workers → Check "Offline"
4. Clear `.next` folder: `rm -r .next` then restart dev server

### Issue: "Build fails with TypeScript errors"
**Solution:**
```bash
rm -r node_modules package-lock.json
npm install
npm run build
```

### Issue: "Port 3000 already in use"
**Solution:**
```bash
# Kill the process on port 3000
netstat -ano | findstr :3000          # Find PID
taskkill /PID <PID> /F                # Kill process

# Or use a different port
npm run dev -- -p 3001
```
